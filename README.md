# WeChatNotes · 微信需求记录

Windows 本地程序，直接读取个人微信的原始消息文字，记录指定群或联系人，并支持手动整理需求、导出本地文件。**当前记录流程不使用截图或 OCR。**

当前为实验性版本，版本号保存在根目录的 [VERSION](VERSION) 文件中。已在 Windows 微信 **4.1.15.53** 上验证数据库连接、消息原文及发送人解析。其他微信版本尚未验证。本项目与微信官方无隶属关系。

| 功能 | 当前支持 |
| --- | --- |
| 记录范围 | 选定群或联系人；可选择首次导入时间范围 |
| 消息来源 | 本地聊天数据库与已提交的 WAL 事务 |
| 同步方式 | 定时同步，默认 30 秒；按消息标识去重 |
| 消息信息 | 原文、发送人、群昵称、发送时间、消息编号、来源数据库 |
| 会话浏览 | “全部”总览及各会话独立标签，每个标签显示最近 500 条 |
| 需求整理 | 手动编辑需求、状态及消息来源链接 |
| 本地导出 | 对话内容 Markdown、原文 Markdown、CSV、JSONL、本地文件附件及原始语音 |

## 运行环境

Windows 10 2004+、x64 系统。独立 EXE 版本包含运行环境和语音解码组件；精简 DLL 版本需要 .NET 10 Desktop Runtime。构建源码需要 PowerShell 7、.NET 10 SDK，以及 Visual Studio 2022 或更新版本的 C++ 桌面开发工作负载。运行发布包无需安装开发工具或单独安装语音转换软件。无需 OCR 组件。

## 使用

1. 将 Windows 发布包完整解压，独立 EXE 版本双击 `WeChatNotes.exe`，DLL 版本双击 `启动.cmd`，保持微信登录。从源码构建时，分别位于 `dist/WeChatNotes-exe/` 和 `dist/WeChatNotes/`。
2. 点击“添加会话”→“读取会话列表”，勾选需要记录的群或联系人。默认自动查找 `Documents/xwechat_files/<账号>/db_storage`；自定义存储位置可手动选择目录。
3. 选择首次导入范围：从添加时开始、最近 24 小时、最近 7 天、全部本地历史。
4. 点击“开始记录”，默认每 30 秒同步一次。无需打开独立窗口；微信窗口可最小化、遮挡、切换或滚动。
5. 在“采集记录”内按会话切换标签，或在“全部”标签查看总览。可搜索当前标签最近 500 条消息的正文、会话、发送人或群昵称。选中消息查看原文、发送人、群昵称、发送时间和来源。“整理为需求”支持编辑名称、说明、状态并关联来源。双击需求清单可继续编辑。
6. 在“采集记录”内切换到具体群或联系人标签，点击顶部“导出当前聊天记录”，暂停同步，在所选目录新建带时间的导出文件夹，生成该会话的 Markdown、CSV、JSONL 及关联需求文档。“全部”总览或尚无记录的会话中禁用该按钮。

导出中的 `对话内容.md` 按发送时间整理为“发送人：内容（时间）”，不混入数据库编号或消息 XML。例如：

```text
A：导出文件请保留需求来源。 （2026-10-23 09:01:00 +08:00）
B：收到，周五完成。 （2026-10-23 09:02:00 +08:00）
C：文件 需求说明.docx （2026-10-23 09:03:00 +08:00）
```

普通文件消息会按原始文件名、大小及可用的 MD5 校验值匹配本机 `msg/file/` 中已下载的文件，复制到 `附件/<消息目录>/<原始文件名>`，并在对话内容和原文 Markdown 中添加相对链接。不同消息分目录保存，同名文件不会互相覆盖。仅有文件名和大小时，必须匹配唯一同名文件。未找到、无法校验或无法复制的文件会保留文件名并注明未导出；先在微信下载后再次导出即可重试，无需重新采集消息。

语音消息会在导出时只读连接来源账号的 `message/media_*.db`，按原始会话、本地消息编号、服务器编号和发送时间精确匹配，保存在 `语音/<消息目录>/`。SILK 语音自动转换成 `语音_年月日_时分秒.wav`，格式为 24 kHz、单声道、16 位 PCM，可用常见播放器打开；同目录保留完整原始 `.silk` 文件。两份 Markdown 默认链接到 WAV，并附原始 SILK 链接；CSV 同时提供播放文件路径、原始语音路径及转换状态。

转换完全在本机进行，发布包内置从附带 SDK 源码编译的解码组件，无需安装 FFmpeg 或连接转换网站。首次转换时，将按内容哈希校验的解码 DLL 缓存到 `%LOCALAPPDATA%/WeChatNotes/codecs/`，其中不保存聊天内容或音频。音频字节在内存中解码，不生成临时明文语音文件。不同消息分目录保存，同一秒发送的语音也不会覆盖。转换失败时保留原始 SILK 并注明原因，继续导出其他消息。识别到 AMR、WAV、Ogg 时保留对应扩展名，未知格式按 `.bin` 原样保存；本次不转换这些格式，不进行语音转文字。

导出语音时请保持微信登录。未找到音频、音频为空、匹配到多条或语音库无法读取时，会在对话中注明未导出原因，文字记录仍正常导出；可先在微信加载语音后重新导出。单条原始音频上限为 32 MiB；转换前按每包最多 5 帧估算容量，限制 PCM 缓冲不超过 32 MiB，超出时仅保留原始音频。移除会话绑定后，已保留的来源目录仍可用于历史语音导出。图片、视频和合并转发中的内嵌附件暂不提取原文件。

本地记录在 `%LOCALAPPDATA%/WeChatNotes/records.sqlite3`。移除会话保留已记录内容；再次添加相同会话不会复制同一条消息。默认启动暂停，点击开始后补采所选范围内仍保存在微信本地库中的消息。旧版截图绑定需要移除并重新选择会话，旧记录仍可查看和导出。

采集记录的“发送人”列直接显示已保存的联系人备注或昵称，没有名称时回退显示微信标识；资料均缺失时标注“未知发送人 / 系统”。已有原文记录无需重新采集即可显示发送人。“群昵称”作为独立补充资料保留在详情和导出中，来自该群的成员资料，与联系人备注分开保存。每次同步刷新成员资料，旧记录会在重新同步时补充当前可读取的群昵称；这是同步时的成员昵称，并非消息发送时的历史昵称。移除绑定后仍保留该会话的历史标签；导出当前会话的全部已采集记录及关联需求，不受搜索条件或列表最近 500 条限制。

独立 EXE 版本无需另装 .NET。DLL 版本通过已安装的 .NET 10 Desktop Runtime 启动，也可在程序目录执行 `dotnet WeChatNotes.dll`。本地构建会另外生成快捷方式；公开发布包使用可随目录移动的启动文件。

## 实现与边界

- 只读打开微信进程以获取数据库配置，通过 HMAC-SHA512 验证数据库密钥。无注入、无进程写入，无源数据库写入。
- 读取加密数据库及 WAL 快照，验证校验码，只使用已提交事务，解密后使用独立的只读内存 SQLite 数据库。**程序不主动将密钥或完整明文聊天库写入文件**，仅选定会话的记录持久化到本地。操作系统分页、休眠和进程转储不在本程序控制范围内。
- 按本地消息标识去重；同文不同消息均保留。同条消息的内容或消息编号变化会更新已保存记录。每轮重新检查所选会话范围，兼顾断点恢复和消息变化。
- 原文不裁剪、不做 OCR、不将 HTML 实体替换为文字。JSONL 的 `Message.RawContent` 保留数据库原始正文；聊天显示正文会去除已确认的群发送人前缀。
- 普通文件附件可在导出时复制本机已有文件；不通过网络下载文件。来源目录保存在本地，移除绑定仍保留，用于历史记录导出。文件名必须为有效的本地文件名，不接受消息中的任意绝对路径或目录跳转。
- 语音在导出时读取本地媒体库，使用各分库自己的会话映射并核对完整消息标识。重复匹配时不猜测、不拼接；音频只导出到当前聊天的导出目录，不将完整明文媒体库落盘。临时音频缓冲在完成后清理。
- 图片、视频和表情保留数据库中的说明或 XML，不转写语音。对话内容 Markdown 将媒体和引用消息转换为可读说明，已导出的文件和语音附带链接；原文 Markdown、JSONL 仍保留原始正文。
- 只覆盖已经同步到这台电脑、选定会话及所选起点之后的消息。已删除且未采集的消息无法恢复，撤回可能改变数据库中的消息内容。电脑休眠期间不会执行同步。
- 轮询间隔不是延迟保证：微信本地落库、数据库大小和写入重试会影响同步时间。微信升级可能需要重新适配。若当前版本无法通过校验，会明确提示连接失败，不会回退到 OCR。
- 运行时无网络接口，不上传聊天内容；保存的记录与导出文件为本地明文。

## 构建与验证

```powershell
.\build.ps1
# 独立单文件 EXE，包含运行环境：
.\build.ps1 -Standalone
.\test.ps1
.\package.ps1
.\package.ps1 -Standalone
# 仅做本机只读连接诊断，报告不含密钥、联系人标识和聊天正文：
dotnet .\dist\WeChatNotes\WeChatNotes.dll --raw-probe .\artifacts\raw-probe.json
```

`test.ps1` 使用合成数据，不连接个人微信。`package.ps1` 从全新目录构建并测试，生成 Windows ZIP、对应源码 ZIP 和 `SHA256SUMS.txt`，输出到 `artifacts/packages/`；不打包现有安装目录。GitHub Actions 会执行同样流程，生成可下载的构建产物。

更新版本时只需修改根目录的 `VERSION`，重新构建后，窗口显示、程序集版本及发布包文件名会同步更新。发布包及对应源码包均附带 `VERSION` 文件。

103 项合成验证覆盖密码校验、页损坏、WAL 提交/未提交/撕裂/截断、只读内存库、中文表情与空白无损、压缩正文、重复同步、同文不同消息、消息编号更新、重启恢复、导出来源链接、会话标签隔离和选择保持、空会话与历史标签、群昵称解析、兼容旧记录、发送人显示回退、当前会话导出隔离、对话时间排序、文件匹配与校验、同名附件、缺失与补下载文件、文件名与 XML 边界，以及语音的会话与消息匹配、分库映射、重复匹配、空音频、原始字节和格式、链接、未加载重试及历史导出。WAV 转换另覆盖 8/16/24 kHz 与 20/60/100 ms 数据包的独立 SDK 参考结果、标准和微信文件头、短语音、损坏与超限输入、Windows WAV 读取、原始文件保留及输出冲突。测试不播放声音，同时在报告旁生成仅包含合成数据的界面预览 PNG。真实微信诊断单独验证，不将聊天正文写入测试报告。旧版 `--self-test` 仅用于遗留截图代码验证。
