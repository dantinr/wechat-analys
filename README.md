# WeChatNotes · 微信需求记录

Windows 本地程序，直接读取个人微信的原始消息文字，记录指定群或联系人，并支持手动整理需求、导出本地文件。**当前记录流程不使用截图或 OCR。**

当前为实验性版本，版本号保存在根目录的 [VERSION](VERSION) 文件中。已在 Windows 微信 **4.1.15.53** 上验证数据库连接、消息原文及发送人解析。其他微信版本尚未验证。本项目与微信官方无隶属关系。

| 功能 | 当前支持 |
| --- | --- |
| 记录范围 | 选定群或联系人；可选择首次导入时间范围 |
| 消息来源 | 本地聊天数据库与已提交的 WAL 事务 |
| 同步方式 | 定时同步，默认 30 秒；按消息标识去重 |
| 消息信息 | 原文、发送人、发送时间、消息编号、来源数据库 |
| 需求整理 | 手动编辑需求、状态及消息来源链接 |
| 本地导出 | Markdown、CSV、JSONL |

## 运行环境

Windows 10 2004+、x64 系统。独立 EXE 版本包含运行环境；精简 DLL 版本需要 .NET 10 Desktop Runtime。构建源码需要 .NET 10 SDK。无需 OCR 组件。

## 使用

1. 将 Windows 发布包完整解压，独立 EXE 版本双击 `WeChatNotes.exe`，DLL 版本双击 `启动.cmd`，保持微信登录。从源码构建时，分别位于 `dist/WeChatNotes-exe/` 和 `dist/WeChatNotes/`。
2. 点击“添加会话”→“读取会话列表”，勾选需要记录的群或联系人。默认自动查找 `Documents/xwechat_files/<账号>/db_storage`；自定义存储位置可手动选择目录。
3. 选择首次导入范围：从添加时开始、最近 24 小时、最近 7 天、全部本地历史。
4. 点击“开始记录”，默认每 30 秒同步一次。无需打开独立窗口；微信窗口可最小化、遮挡、切换或滚动。
5. 选中消息查看原文、发送人、发送时间和来源。“整理为需求”支持编辑名称、说明、状态并关联来源。双击需求清单可继续编辑。
6. “导出全部”暂停同步，在所选目录新建带时间的导出文件夹，生成 Markdown、CSV、JSONL 及需求文档。

本地记录在 `%LOCALAPPDATA%/WeChatNotes/records.sqlite3`。移除会话保留已记录内容；再次添加相同会话不会复制同一条消息。默认启动暂停，点击开始后补采所选范围内仍保存在微信本地库中的消息。旧版截图绑定需要移除并重新选择会话，旧记录仍可查看和导出。

独立 EXE 版本无需另装 .NET。DLL 版本通过已安装的 .NET 10 Desktop Runtime 启动，也可在程序目录执行 `dotnet WeChatNotes.dll`。本地构建会另外生成快捷方式；公开发布包使用可随目录移动的启动文件。

## 实现与边界

- 只读打开微信进程以获取数据库配置，通过 HMAC-SHA512 验证数据库密钥。无注入、无进程写入，无源数据库写入。
- 读取加密数据库及 WAL 快照，验证校验码，只使用已提交事务，解密后使用独立的只读内存 SQLite 数据库。**程序不主动将密钥或完整明文聊天库写入文件**，仅选定会话的记录持久化到本地。操作系统分页、休眠和进程转储不在本程序控制范围内。
- 按本地消息标识去重；同文不同消息均保留。同条消息的内容或消息编号变化会更新已保存记录。每轮重新检查所选会话范围，兼顾断点恢复和消息变化。
- 原文不裁剪、不做 OCR、不将 HTML 实体替换为文字。JSONL 的 `Message.RawContent` 保留数据库原始正文；聊天显示正文会去除已确认的群发送人前缀。
- 图片、语音、视频、表情和文件仅保留数据库中的说明或 XML，不下载原文件、不转写语音。引用消息可能以 XML 显示。
- 只覆盖已经同步到这台电脑、选定会话及所选起点之后的消息。已删除且未采集的消息无法恢复，撤回可能改变数据库中的消息内容。电脑休眠期间不会执行同步。
- 轮询间隔不是延迟保证：微信本地落库、数据库大小和写入重试会影响同步时间。微信升级可能需要重新适配。若当前版本无法通过校验，会明确提示连接失败，不会回退到 OCR。
- 运行时无网络接口，不上传聊天内容；保存的记录与导出文件为本地明文。

## 构建与验证

```powershell
.\build.ps1
# 独立单文件 EXE，包含运行环境：
.\build.ps1 -Standalone
.\test.ps1
.\package.ps1
.\package.ps1 -Standalone
# 仅做本机只读连接诊断，报告不含密钥、联系人标识和聊天正文：
dotnet .\dist\WeChatNotes\WeChatNotes.dll --raw-probe .\artifacts\raw-probe.json
```

`test.ps1` 使用合成数据，不连接个人微信。`package.ps1` 从全新目录构建并测试，生成 Windows ZIP、对应源码 ZIP 和 `SHA256SUMS.txt`，输出到 `artifacts/packages/`；不打包现有安装目录。GitHub Actions 会执行同样流程，生成可下载的构建产物。

更新版本时只需修改根目录的 `VERSION`，重新构建后，窗口显示、程序集版本及发布包文件名会同步更新。发布包及对应源码包均附带 `VERSION` 文件。

原文流程的 21 项合成验证覆盖密码校验、页损坏、WAL 提交/未提交/撕裂/截断、只读内存库、中文表情与空白无损、压缩正文、重复同步、同文不同消息、消息编号更新、重启恢复和导出来源链接。真实微信诊断单独验证，不将聊天正文写入测试报告。旧版 `--self-test` 仅用于遗留截图代码验证。

主要文件：`RawDatabase.cs`（密钥验证与页/WAL 读取）、`RawChatSource.cs`（只读内存库、会话及消息解析）、`RawRecorder.cs`（轮询）、`RawBindDialog.cs`（会话选择）、`Store.cs`（本地保存）、`Exporter.cs`（导出）。
